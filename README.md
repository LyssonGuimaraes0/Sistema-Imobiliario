# Sistema de Imobiliario

## 📌 Descrição
Aplicação web desenvolvida para gerenciamento e exibição de imóveis, permitindo o cadastro de imoveis, organização e busca eficiente de propriedades. O sistema tem como foco oferecer uma experiência intuitiva tanto para administradores quanto para usuários finais interessados em visualizar imóveis.

## 🚀 Tecnologias
- PHP (Back-end)
- MySQL (Banco de Dados)
- JavaScript (Front-end)
- AJAX (Requisições assíncronas)

## ⚙️ Instalação
1. Clonar o repositório
2. Configurar .env
3. Rodar o banco de dados
4. Rodar o projeto localmente

## 📷 Funcionalidades
🏡 Cadastro e gerenciamento de imóveis (em evolução)
🔎 Sistema de busca com filtros dinâmicos (preço, localização, etc.)
⚡ Renderização assíncrona com AJAX (sem reload de página)
🖼️ Upload e manipulação de imagens
📇 Exibição de dados do proprietário (cartão de contato)
📄 Paginação dinâmica no front-end
🔗 API REST própria para comunicação entre front e back

🧠 Decisões Técnicas
- Estrutura baseada em MVC, separando regras de negócio, controle e apresentação
- Criação de roteador customizado em PHP para controle de endpoints
- Uso de Fetch + JSON para desacoplamento entre front-end e back-end
- Manipulação dinâmica do DOM para melhorar a experiência do usuário
- Organização de código visando escalabilidade e manutenção

📈 Diferenciais
- Desenvolver um sistema real de imobiliária com fluxo completo de dados
- Arquitetura preparada para evolução (ex: autenticação, painel admin)
- Foco em performance com carregamento parcial de conteúdo
- Código estruturado sem uso de frameworks, reforçando domínio dos fundamentos

🎯 Objetivo do Projeto
- Demonstrar domínio em desenvolvimento full-stack com PHP e JavaScript, aplicando boas práticas de arquitetura, consumo de API e construção de interfaces dinâmicas.
